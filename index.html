First completed notebook

SPX implied volatility surface reconstruction

A Kaggle notebook that reconstructs an SPX implied volatility surface from listed option quotes. The project cleans raw option-chain data, estimates forwards through put-call parity, inverts Black-76 prices and visualizes implied volatility by moneyness and maturity.

Project summary

first project

Objective: rebuild a clean implied-volatility surface from SPX option quotes rather than using a precomputed volatility dataset.

Dataset: two files, Chain.csv for option quotes and Meta.csv for spot, valuation date and flat interest-rate assumptions.

Method: filter illiquid quotes, match calls and puts by strike and expiry, estimate forward prices, keep out-of-the-money options, then solve for Black-76 implied volatility.

Important limitation: this is a first notebook project, not a production volatility model. It uses a flat rate, mid prices and simplified filtering assumptions.

Second notebook project

Black-Scholes and Heston implied volatility surfaces

A quantitative notebook comparing constant-volatility Black-Scholes surfaces with Heston stochastic-volatility surfaces. The project implements Black-76 implied-volatility inversion, Heston semi-closed pricing, Monte Carlo simulation under stochastic variance and sensitivity analysis for key Heston parameters.

Project summary

second project

Objective: compare how Black-Scholes and Heston generate implied-volatility surfaces across log-moneyness and maturity.

Mathematical framework: Black-76 pricing, implied-volatility inversion, stochastic variance, Heston characteristic function and Monte Carlo simulation.

Models compared: constant-volatility Black-Scholes, Heston semi-closed formula and Heston Monte Carlo with full truncation Euler discretization.

Assumptions: synthetic input parameters, flat interest rate, flat dividend yield, fixed Heston parameters and simplified numerical integration settings.

Important limitation: this is a numerical prototype, not a calibrated production model. The parameters are chosen for learning and comparison, not fitted to live market data.

Monte Carlo simulation for European option pricing

in progress

Objective: estimate European call option prices by simulating terminal asset prices.

Mathematical framework: geometric Brownian motion, Brownian increments, risk-neutral valuation and discounted expected payoff.

Assumptions: constant volatility, constant risk-free rate, no dividends, no arbitrage and European exercise only at maturity.

Python tools: NumPy, pandas and matplotlib.

Next milestones: compare results with Black-Scholes, add confidence intervals and study convergence as the number of simulated paths increases.

import numpy as np

def monte_carlo_call_price(S0, K, r, sigma, T, paths=50_000):
    z = np.random.standard_normal(paths)
    ST = S0 * np.exp((r - 0.5 * sigma**2) * T + sigma * np.sqrt(T) * z)
    payoff = np.maximum(ST - K, 0)
    return np.exp(-r * T) * payoff.mean()

Black-Scholes formula

from math import erf, exp, log, sqrt

def normal_cdf(x):
    return 0.5 * (1 + erf(x / sqrt(2)))

def black_scholes_call(S, K, r, sigma, T):
    d1 = (log(S / K) + (r + 0.5 * sigma**2) * T) / (sigma * sqrt(T))
    d2 = d1 - sigma * sqrt(T)
    return S * normal_cdf(d1) - K * exp(-r * T) * normal_cdf(d2)

Monte Carlo simulation skeleton

def simulate_terminal_prices(S0, r, sigma, T, n_paths):
    shocks = np.random.normal(0, 1, n_paths)
    drift = (r - 0.5 * sigma**2) * T
    diffusion = sigma * np.sqrt(T) * shocks
    return S0 * np.exp(drift + diffusion)

Regression skeleton with statsmodels

import statsmodels.api as sm

def run_factor_regression(data, target, factors):
    X = sm.add_constant(data[factors])
    y = data[target]
    result = sm.OLS(y, X, missing="drop").fit()
    return result.params, result.pvalues, result.rsquared

Portfolio volatility calculation

def annualized_portfolio_volatility(returns, weights):
    weights = np.asarray(weights)
    annual_covariance = returns.cov() * 252
    variance = weights.T @ annual_covariance @ weights
    return np.sqrt(variance)
